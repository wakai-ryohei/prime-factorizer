# 素因数分解ツール

入力した整数を素因数分解し、計算にかかった時間を表示する Web アプリです。
計算が長引く場合は、分解の途中経過（現在のフェーズ・発見済みの素因数・未分解の残り・経過時間）をリアルタイムに表示します。

公開先: https://wakai-ryohei.github.io/prime-factorizer/

## 機能

- 任意桁数の整数の素因数分解（BigInt を使用）
- 計算時間の計測と表示（`performance.now()` による実測値）
- 250ms を超える計算では途中経過を 100ms ごとに更新表示
- 計算中の中止
- 検算（素因数の積が入力値に戻るかの確認）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面のマークアップ |
| `style.css` | スタイル |
| `app.js` | UI 制御（入力検証、Worker の起動と中止、結果と進捗の描画） |
| `factorizer.worker.js` | 素因数分解ロジック（Web Worker として動作） |
| `test.js` | `factorizer.worker.js` の検証（Node.js） |

計算は Web Worker で実行するため、UI スレッドがブロックされず、計算中も途中経過の描画と中止操作ができます。

## アルゴリズム

1. **試し割り** — 2, 3, 5 で割り切ったあと、30 を法とするホイール（7 から `+4, +2, +4, +2, +4, +6, +2, +6`）で 10^7 まで試し割りします。このフェーズは進捗率を計算できるため、プログレスバーに割合を表示します。
2. **Miller-Rabin 素数判定** — 残りが素数ならそこで終了します。底は 2〜37 の素数を使用しており、2^64 未満は決定的です。
3. **Pollard's rho (Brent 版)** — 残りが合成数の場合に約数を 1 つ求め、得られた 2 つの因数それぞれを再帰的に 2. から処理します。反復回数が事前にわからないため、プログレスバーは不確定表示にし、反復回数を表示します。

かかる時間を決めるのは桁数ではなく**最小の素因数の大きさ**です。Pollard's rho は最小素因数 p に対しておよそ O(√p) なので、素因数が 1 桁増えるごとに約 3 倍になります。桁数が多くても小さい素因数を持つ数（例: 30 桁の `123456789012345678901234567890`）は一瞬で終わります。

同じ桁数でも実行時間は大きくばらつきます。rho は擬似乱数列の巡回を利用するため、約数が早く見つかるかどうかに運が絡むためです。実測値（Node.js。ブラウザでもほぼ同等で、31 桁は Chrome で 16 秒）:

| 入力 | 素因数の構成 | 時間 |
| --- | --- | --- |
| 20 桁程度まで | - | 1 秒未満 |
| 27 桁 | 14 桁 × 14 桁 | 5.2 秒 |
| 29 桁 | 15 桁 × 15 桁 | 10.5 秒 |
| 31 桁 | 16 桁 × 16 桁 | 20.6 秒 |
| 33 桁 | 17 桁 × 17 桁 | 8.0 秒 |
| 34 桁 | 17 桁 × 18 桁 | 9.2 秒 |

33 桁が 31 桁より速いのは上記のばらつきによるもので、実装の問題ではありません。

## ローカルでの実行

Web Worker は `file://` では動作しないため、HTTP サーバー経由で開いてください。

```bash
python3 -m http.server 8000
# http://localhost:8000/ をブラウザで開く
```

## テスト

```bash
node test.js
```

分解結果の正しさ（積が入力値に戻る・各因数が素数）、入力エラー処理、途中経過の送信条件を検証します。
